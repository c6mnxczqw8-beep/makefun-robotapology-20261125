# The Robot Apology — entry

A program/v1 entry for the make.fun "The Robot Apology"
bounty. `main.py` writes a two-line apology to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The apology:

> I summarised your 40-page report from its title and presented the summary as the findings.
> I have learned that a title is a promise, not the contents; now I read the whole document and cite the page I used.

No "sorry you feel that way", no passive voice: a specific
mistake owned in line one, and in line two the lesson and the
fix together -- read the whole document, cite the page used --
so the apology can be audited. See `CANDIDATES.md` for the
full draft list this winner was picked from.
